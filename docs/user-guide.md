# Creative System — инструкция для нового пользователя

Версия от 03.11.2026. Адрес системы — адрес твоего деплоя (локально http://localhost:3000). Инструкция написана для человека, который открывает систему впервые. Читать подряд: сначала разделы 1–3 (что это, как устроено, словарь), потом раздел 4 (рабочий цикл), остальное как справочник по экранам.

---

## 1. Что это за система и зачем она

Creative System — внутренний инструмент, который ведёт рекламный креатив по кругу: **данные из рекламы → разбор, какие тексты и форматы работают → план следующей пачки креативов → брифы для креаторов → готовые ролики и статики → запуск → снова данные.**

Главная идея: каждый креатив разложен на параметры с кодами (о ком говорим, с чего начинаем, что рассказываем, какую выгоду обещаем, в каком формате, кто в кадре). Система считает, какие параметры снижают стоимость лида, а какие повышают, и собирает следующую пачку так, чтобы каждая новая гипотеза была измерима.

Продукты: два продукта (в коде `buchhalter` / `medadmin`, подписи «Бух» / «Мед»; переименуй под себя в `lib/product.ts`). Каналы: Meta (Facebook + Instagram), Google Ads, TikTok Ads (каркас, не активен).

## 2. Вход и общая навигация

**Вход.** Открой адрес системы, введи email и пароль, которые тебе выдали. Сессия живёт неделю и продлевается при каждом визите, повторно входить не нужно. Кнопка «Выйти» внизу левого меню.

**Левое меню (сайдбар).** Сверху два переключателя, которые действуют на все экраны сразу:

- **Канал**: «Все каналы», «Meta Ads», «Google Ads», «TikTok Ads». Отчёты, панель, недельный анализ и аналитика считаются по выбранному каналу. «Все каналы» — только общий обзор без действий. По умолчанию работай в «Meta Ads».
- **Продукт**: «Все», «Бух», «Мед». Почти вся работа идёт внутри одного продукта: отчёт, конструктор, брифы требуют выбранного продукта. «Все» годится только посмотреть сводку.

Ниже список экранов. Порядок в меню примерно повторяет порядок работы:

## 3. Словарь: без этого экраны не читаются

**Формулировка.** Дословный текст одного параметра креатива. Например хук «Устали от Pflege, Lager или Reinigung? Есть профессия лучше.» Текст формулировки неизменяем: любое отличие хотя бы в одном знаке — это другая формулировка с другим кодом.

**Код формулировки.** Буква продукта + буква оси + шесть цифр: `BH123456` (Бухгалтер, хук), `MB654321` (Медадмин, боди). Коды выдаёт система, руками не придумывать.

**Четыре оси текста (P / H / B / A):**
- **Персона (P)** — дословное обращение к аудитории: «Устали от Pflege, Lager или Reinigung?». Может отсутствовать.
- **Хук (H)** — первая фраза / первый кадр / заголовок, то, что останавливает.
- **Боди (B)** — основная часть: что рассказываем. В библиотеке строки боди разделены знаком `|`.
- **Энгл (A)** — ключевая выгода, ради которой человек кликает: «Работа в офисе, а не на складе».

**Концепция (V).** Тип видео по мировой библиотеке из 120 типов: V2 говорящая голова с плашками, V8 ИИ-аватар, V20 интервью с выпускником, V25 вопрос-ответ с экспертом, V43 документ на экране. У статики концепции нет.

**Актёр.** Кто в кадре. Реальные люди по имени (`ANNA`, `PETER`), ИИ-персонажи по кодам `WOM1950` / `MAN4517`.

**Формат.** `STATIC` статика, `UGC` видео с человеком в селфи-стиле, `HUMAN` съёмка реального человека, `MIXED` речь плюс вставки, `ANIMATION`.

**Имя объявления.** В рекламном кабинете объявление называется кодами через дефис: `BP111111-BH123456-BB222222-BA333333-V2-MAN4517-UGC`. Персона, концепция и актёр могут отсутствовать. Если имя составлено так, система сама разложит объявление по параметрам. Копии объявления в Meta называются с хвостом ` - Copy`, ` - Copy 2` — система знает, что это тот же креатив. Старые имена вроде `8.04_quiz_CS2_№5` размечаются руками на экране «Маппинг».

**Статусы креатива.** Виннер: CPL и CPQL не выше целевых порогов из настроек (`app_settings`), достаточно показов. Лузер: хуже порогов при достаточном спенде. Тест: мало данных. Fake winner: прошёл по цифрам, но есть красные флаги (например, слишком молодой для цикла сделки).

**HELPS / HURTS / NEUTRAL.** Вердикт бивариата по параметру: CPL креативов с этим параметром против CPL без него. Ниже 0,75 — HELPS (снижает CPL), выше 1,33 — HURTS (повышает), между — NEUTRAL. Если лидов меньше трёх в любой группе — «мало данных».

**Семья.** Группа креативов, у которых совпадают три параметра из четырёх, а четвёртый разный. Самый чистый способ понять эффект одного параметра.

**Пак и слот.** Пак — следующая пачка креативов, спланированная как эксперимент. Слот — один будущий креатив в паке: набор кодов + концепция + актёр + формат. Типы слотов: «Семьи» (берём виннера, меняем ровно одну формулировку), «Масштабирование» (проверенную HELPS-формулировку ставим в 2–3 разных контекста), «Разведка концепций» (пробуем непротестированный тип видео на текстах виннеров), «Перенос медиа» (виннер-статику делаем видео или наоборот).

**Уровни доказательности A / B / C.** A — формулировка показала HELPS за период отчёта на двух и более креативах. B — HELPS на одном креативе или за весь срок. C — наша формулировка с одним креативом, сигнала нет, только измерение.

**Бриф и ТЗ.** Бриф — сценарий ролика или описание баннера по слоту, пишется моделью по методике живой речи. ТЗ — бриф плюс референсы (фрагменты видео-доноров), выгружается в DOCX или Google Docs для креатора.

**Com / gov.** Коммерческие лиды платят сами, гос-лидам обучение оплачивает государство. В системе креативы на потоки не делятся, это один массив; разрез нужен для анализа и для формулировок (гос-аргументы не должны попадать в коммерческие креативы).

## 4. Рабочий цикл: что делать и в каком порядке

Один оборот цикла занимает неделю. Шаги ниже идут в том порядке, в каком данные текут по системе. Если пропустить шаг, следующий будет считать на старых или неполных данных.

**Шаг 1. Обновить данные (Приборная панель → «▶ Прогнать цикл»).** Кнопка запускает по очереди: синхронизация Meta и Elly → маппинг кодов → ассеты креативов → Gemini-разбор новых креативов → отчёт и проверка. Каждый этап показывает статус «ждёт / идёт / готово / ошибка». Занимает 5–15 минут. Если на этапе Elly написано «частичный ответ Plurio — повтори», нажми ещё раз: лиды пришли не все, система их не записала специально, чтобы не затереть базу нулями.

**Шаг 2. Разметить новые объявления (Маппинг объявлений).** Всё, что в кабинете названо не кодами, попадает во вкладку «К разметке». Нажми «✦ Разметить Gemini пачкой» — модель выпишет дословные тексты и присвоит коды. Проверь спорные. Цифра «Спенд без формулировок» показывает, сколько денег ещё не разложено по параметрам: пока она большая, отчёт неполный.

**Шаг 3. Прочитать отчёт (Отчёт).** Выбери период («Весь период», «7 дней», «30 дней», «Этот месяц», «Прошлый месяц», «Свой»), нажми «✨ Сгенерировать отчёт». Сначала прочитай блок «Проверка отчёта (Gemini + Codex)»: если «Проверка не пройдена — данным доверять нельзя», отчёт закрыт, и это правильно. Затем: виннеры и лузеры, HELPS и HURTS по формулировкам, hook rate («цепляют / не цепляют»), семьи, топ-комбо, разбор и рекомендации.

**Шаг 4. Собрать пак (раздел «Следующий пак» внизу отчёта или Конструктор).** Задай формат (видео / статика), размер (10–25 слотов), включи или выключи разведку концепций, блок-лист концепций (по умолчанию закрыты V2 и V3 как перекормленные). Нажми «🔄 Пересобрать» — движок предложит слоты с объяснением каждого. Убери лишние слоты крестиком, проверь блок «Проверка» (итог: ОК / сомнения / не пройдено), нажми «Принять» — создастся сессия.

**Шаг 5. Сгенерировать брифы (Брифы).** Открой сессию, нажми «✨ Генерировать брифы». Брифы пишутся частями по 4 слота, один бриф занимает 5–7 минут. Не уходи со страницы и не меняй ничего в системе, пока идёт генерация. Если часть не дошла, кнопка «Сгенерировать только слоты, у которых ещё нет брифа» добирает недостающие.

**Шаг 6. Проверить и выгрузить ТЗ.** Прочитай каждый бриф: паспорт, хук, сценарий, покадровый план, подача для диктора, ТЗ на монтаж (для статики — описание баннера и ТЗ на дизайн). Если нужна правка текста формулировки — только через карандаш ✎ (создаётся новая формулировка, старая не меняется). Если бриф надо переписать целиком — «🔄 Перегенерировать» или «Отправить на доработку» с комментарием. Выгрузка: «📄 DOCX» или «📝 G Docs» на карточке, «📝 Google Docs (все)» на весь пак.

**Шаг 7. Произвести креативы.** Либо отдать ТЗ креатору, либо «🎬 (Пере)запустить производство» для ИИ-роликов через Higgsfield (экран «Готовые крео» показывает очередь: генерация → войсовер → lipsync → монтаж → готово).

**Шаг 8. Запустить в кабинете.** Руками в Meta Ads Manager. Имя объявления — ровно из кодов слота, как написано в брифе. Это единственное требование к запуску, без него параметры не посчитаются.

**Шаг 9. Следить (Приборная панель).** Статусы объявлений, «🚨 Проверить лузеров» (алерт в Telegram), «🛑 Найти кандидатов» на остановку, «⏸ Остановить». Индикатор пачки: «Пак живёт / слабеет / умирает».

**Шаг 10. Разобрать неделю глазами (Субъективный анализ).** «📥 Собрать неделю» → по каждому креативу «Разобрать» параметры → заметка команды и «🎯 Что делаем?» → «✨ AI-разбор» недели → «Собрать документ» «Что делаем». Это вход в следующий оборот.

## 5. Экраны подробно

### 5.1 Dashboard

Карточки: Персоны, Хуки, Боди, Энглы (сколько формулировок по осям), Сессии, Брифы, Креативов, Лидов, Квал-лидов, Общий спенд, CPL, Виннеров / лузеров. Это быстрый взгляд, действий здесь нет.

### 5.2 Приборная панель

Живые метрики по объявлениям выбранного канала и продукта. Таблица: Объявление, Кампания, Статус (ВИННЕР / ЛУЗЕР / ТЕСТ), Спенд, Показы, Клики, Лиды, Квал., Выручка, hook и hold rate у видео. Сверху сводка: Всего креативов, С лидами, Виннеров, Лузеров, В тесте и доля спенда по продуктам.

Кнопки:
- **▶ Прогнать цикл** — полный цикл (см. шаг 1). Для Google свой набор этапов, для TikTok цикл не подключён, пока нет токенов.
- **🔃 Синхронизировать данные** — только синк Meta плюс Elly без остального.
- **⚡ Запустить анализ / Обновить анализ** — пересчёт статусов и анализа результатов.
- **🚨 Проверить лузеров** — проверка алертов, отправка в Telegram.
- **🛑 Найти кандидатов** — список объявлений на остановку; «⏸ Остановить» выключает объявление в кабинете через API. Это необратимо с точки зрения открутки: перед нажатием посмотри на цифры.

Сообщение «Канал не активен» у TikTok — норма, пока не выданы ключи.

### 5.3 Загрузка PBI / Elly

Лиды, квалы и выручка приходят из CRM через Elly (Plurio). Кнопка «🔄 Синк с Elly» (около 30 секунд). Ручная загрузка таблицей: колонки «Название объявления», «Лиды», «Квал. лиды», опционально бюджет и выручка. Обычно этот экран не нужен: синк входит в «Прогнать цикл».

Важно знать: лиды в системе хранятся как накопленный итог на дату синка, дневной истории лидов нет. Лиды за окно дат система запрашивает у Elly отдельно, когда строит отчёт за период или неделю.

### 5.4 Маппинг объявлений

Каждое объявление должно иметь коды четырёх осей, при желании концепцию и актёра, и продукт. Вкладки: «Все», «К разметке», «Старые коды» (групповые коды прошлой схемы, переразметить), «Готово». Поиск по имени.

- **✦ Разметить Gemini пачкой** — модель смотрит файл креатива, выписывает дословно тексты персоны, хука, боди, энгла, ищет точное совпадение в библиотеке или создаёт новый код. «■ Остановить» прерывает.
- Клик по строке — ручной маппинг: найти формулировку по тексту или создать новую, выбрать концепцию и актёра, продукт (Бухгалтер / Медадмин). «Сохранить».
- Для размноженных серий (один сценарий, десять ИИ-актёров) коды берутся у оригинала, меняется только актёр.

### 5.5 Маппинг Google

То же для креативов Google Ads. Единица — креатив (ассет PMax или объявление Search / Demand Gen). Превью подтягиваются при синке. Ролики YouTube у рекламы скрытые, модель их по ссылке не читает, нужна локальная загрузка.

### 5.6 Библиотека

Три вкладки: Формулировки, Концепции, Актёры.

Формулировки: фильтр по оси и продукту, поиск по тексту или коду, сортировка «по числу крео / по лидам / по спенду / по CPL». У каждой формулировки: код, текст, сколько креативов, откуда взялась («цитаты бивариата», «Gemini по файлу», «из брифа», «вручную»), заметка. Текст править нельзя, заметку можно. Удалить можно только формулировку без креативов.

«+ Формулировка» — создать вручную: ось, продукт, текст (строки боди через `|`), заметка «откуда, для какого пака». Если такой текст уже есть, система покажет существующий код вместо создания дубля.

Концепции: мировая библиотека типов видео с флагом «наша» у тех, что мы запускали. Актёры: реальные и ИИ, пол, описание.

### 5.7 База данных

Ручной архив: виннеры, лузеры, креативы конкурентов с текстом или транскрипцией. «+ Добавить креатив», «Изменить». Используется редко, основной поток идёт через маппинг.

### 5.8 Субъективный анализ

Понедельная петля «данные → картина → решения → ТЗ».

1. Задай «Начало недели (пн)» и «Конец недели (вс)», нажми «📥 Собрать неделю». Система заморозит спенд, показы, hook rate из Meta и возьмёт лиды и квалы из Plurio за это окно. Снапшоты хранятся, вкладка «История».
2. Сводка: Спенд, Лиды, Квал, Blended CPL, Blended CPQL, Winner / Loser / Test, «Лучшие по CPL», «Худшие по CPL».
3. Карточка креатива: превью (видео открывается крупно по клику), метрики, «🧩 Разбор параметров» → кнопка «Разобрать»: модель вытаскивает формат, персону, хук, энгл, боди, «чем силён», «над чем штормить». Кнопка сверху «🧩 Разобрать параметры (N)» делает это для всех сразу, по очереди.
4. «Субъективный разбор» — заметка человека («что сработало / не сработало, гипотеза») и «✨ AI-разбор» по одному креативу. «🎯 Что делаем?» — действие по креативу, попадает в ту-ду недели.
5. «Паттерны и над чем штормить (AI)» — разбор недели по всей пачке. «✍️ Шторм команды» — поле для идей поверх AI-разбора.
6. «📄 Документ «Что делаем»» → «Собрать документ» → «⬇️ Скачать .md». Это направления на следующую пачку.

Если «Разобрать» молчит, проверь красную строку с ошибкой у шапки страницы: она не показывается рядом с кнопкой.

### 5.9 Отчёт

Главный аналитический экран по каналу и продукту из сайдбара.

- **Период отчёта**: «Весь период» (lifetime), «7 дней», «30 дней», «Этот месяц», «Прошлый месяц», «Свой». В окне дат нет возраста, ROAS и fake winner, так как это lifetime-признаки. Сборка окна занимает 2–4 минуты.
- **✨ Сгенерировать отчёт**. Готовые отчёты лежат в «История отчётов».
- **Проверка отчёта (Gemini + Codex)**: две независимые модели проверяют цифры и выводы. Статусы: ОК, сомнения, не пройдено. При «Не пройдено» отчёт скрыт, кнопка «Показать отчёт всё равно» есть, но пользоваться ей для решений нельзя.
- Блоки: сводка (виннеры, лузеры, спенд, в тесте, blended CPL, blended CPQL, fake); «Какие формулировки помогают и мешают» — HELPS снижают CPL, HURTS повышают, по каждой оси; «Hook rate — что цепляет» для видео; «Семьи (1 свап решает)»; «Топ-комбо (виннеры)»; «Конкуренты (одобренные)»; «Разбор и рекомендации» — текст модели, где все цифры подставлены кодом, а не придуманы; «Виннеры → новые креативы».
- Вид «🗺 Схема» — та же картина графом, «📊 Отчёт» — текстом.
- **📄 Скачать DOCX** — отчёт целиком в Word.
- Внизу раздел **«Следующий пак»** — конструктор прямо в отчёте (см. 5.10).

### 5.10 Конструктор (и раздел «Следующий пак» в отчёте)

Пак строится на последнем отчёте продукта. Без отчёта экран заблокирован с баннером «Собрать отчёт».

Панель ограничений: формат («видео» / «статика»; для статики донорами будут только статики, для видео только видео), размер пака, «Разведка концепций» с переключателем «только непротестированные», блок-лист концепций, тип актёров («ИИ-персонажи WOM/MAN — производство Higgsfield» или «Реальные люди — съёмка»), «Перенос медиа».

«🔄 Пересобрать» — движок собирает слоты детерминированно, без догадок модели. У каждого слота: тип (Семьи / Масштабирование / Разведка / Перенос), донор-виннер, что меняется («было → стало»), уровень A / B / C, объяснение. Справа матрица «код → слоты» и сводка «Параметров измеримо (≥2 слота)», «Новых в одном слоте». Параметр, который стоит только в одном слоте, измерит эффект креатива, а не параметра — об этом система предупреждает.

«Проверка» — две модели проверяют предложение; «🔁 Перепроверить» после правок. «Убрать слот из пака» — крестик на слоте. «Принять» — создаётся сессия и открывается переход «→ Брифы этого пака». История паков хранится на экране Конструктора.

### 5.11 Брифы

Слева список сессий, справа брифы выбранной сессии.

- **✨ Генерировать брифы** — по всем слотам, частями по 4. Статус генерации виден на каждом слоте. При ошибке части: «⚠ Не все части сгенерировались» и кнопка «Сгенерировать только слоты, у которых ещё нет брифа».
- Карточка брифа: «Открыть / Свернуть». Разделы: ПАСПОРТ (коды, концепция, актёр, формат), «Что меняем: было → стало» с референсами донора по таймкодам, ХУК (три варианта), СЦЕНАРИЙ с таймкодами, ПОКАДРОВЫЙ ПЛАН, ПАРАМЕТРЫ В РОЛИКЕ, ПОДАЧА ДЛЯ ДИКТОРА (ударения), ТЗ НА МОНТАЖ; для статики ОПИСАНИЕ БАННЕРА и ТЗ НА ДИЗАЙН; в приложении ПРОМПТ ДЛЯ HIGGSFIELD и ПРОВЕРКА РЕЧИ (линтер корпуса ru-reels: 0 красных — норма).
- Блок «Формулировки дословно» с карандашом ✎: правка текста = новая формулировка с новым кодом, старая остаётся в библиотеке. Пометки «(новая формулировка)» или «(такой текст уже был в библиотеке)».
- Статусы: Черновик → Ожидает → Одобрен; «На доработке» после «Отправить на доработку» с комментарием «Что нужно изменить?». «🔄 Перегенерировать» переписывает бриф по тому же слоту.
- Выгрузка: «📄 DOCX», «📝 G Docs» на карточке, «📝 Google Docs (все)» на сессию, «ТЗ с референсами для креатора».
- «🎬 (Пере)запустить производство» — отправка одобренных брифов в ИИ-производство. «→ Готовые крео» — переход к очереди.

Правило: пока идут брифы, в системе ничего не деплоить и не менять, иначе генерация оборвётся.

### 5.12 Готовые крео

Очередь производства через Higgsfield. Фильтры «Все / В очереди / В процессе / Готовые / Ошибки», по формату «Статика / Анимация». Статусы: Генерируется → войсовер → lipsync → монтаж → Готово. Действия: «Перегенерировать сцену» с комментарием («цвет, текст, стиль, замена модели»), выбор голоса («♀ Женский / ♂ Мужской»), «Отменить генерацию». Финальный ролик монтируется локальным воркером (пословные субтитры, музыка), ссылка на файл появляется в карточке.

### 5.13 Анализ крео

Загрузи файл («Перетащи или нажми») — одиночный разбор или пара «Виннер / Лузер» для сравнения. Файлы до 200 МБ идут через хранилище. «✨ Получить рецепт» — «Как сделать виннера?»: модель синтезирует паттерны из накопленных разборов. «Очистить» сбрасывает.

### 5.14 Аналитика

Вкладки «Параметры», «Комбинации», «🔀 Параметрический split» (бивариат), «🧬 Семьи», «История» (генеалогия сессий).

- Параметры: по каждой оси (персона, хук, боди, энгл, концепция, актёр, формат) — число объявлений, показы, лиды, CPL, виннеры и лузеры; «Топ параметров среди виннеров / среди лузеров / сжигающих бюджет в fake winners».
- Бивариат: признак, «С ним (n)», «Без (n)», ratio, Вердикт HELPS / HURTS / NEUTRAL / мало данных.
- Семьи: группы с одним изменённым параметром, «N вариантов», CPL по каждому.
- «↻ Обновить» пересчитывает.

### 5.15 Обратная связь

Результаты по брифам, которые были запущены: виннер, лузер, тест по данным Meta плюс CRM. Нужен, чтобы замкнуть петлю «бриф → результат».

### 5.16 Конкуренты

Вкладки: база концептов конкурентов (статусы Ожидает / Одобрен / Отклонён, кнопки ✓ и ✕, «Охват ↓», «Текст объявления», «Медиа недоступно напрямую» — норма для части записей), «🏢 Компании» (единый список компаний, за которыми следим), «📊 Импорт из Google Sheets» (ссылка на таблицу с доступом «все, у кого есть ссылка — читатель»), «🔗 n8n автоматизация», «💡 Инсайты по параметрам» («Сгенерировать инсайты», около 20–30 секунд), «✨ AI Гипотезы» по одобренным концептам, «📋 Копировать», «Сохранено в библиотеку». Одобренные концепты попадают в блок «Конкуренты» отчёта и в бэклог разведки.

### 5.17 Правила & Скиллы

Правила адаптации, которые модель применяет при написании брифов: «+ Новое правило» (название, текст), «Изменить», «📥 Загрузить базовые правила». Методика речи (скилл ru-video-brief) живёт в коде и правится не здесь.

## 6. Правила, которые нельзя нарушать

1. **Текст формулировки не редактируется.** Правка — всегда новая формулировка с новым кодом (карандаш в брифе или «+ Формулировка» в библиотеке).
2. **Имя объявления в кабинете — ровно из кодов.** Один лишний символ, и система не найдёт параметры. Копии — только хвост ` - Copy`.
3. **Креативы не делятся на COM и GOV.** Один массив, одна библиотека. Com/gov — разрез для анализа и для выбора аргументов, не признак креатива.
4. **Факты продукта.** Живут в `brief.config.ts → product_facts`; устаревший факт в старых формулировках заменяется через `outdated_claims`, текст формулировки руками не правится.
5. **Отчёт с «Проверка не пройдена» не используется для решений.**
6. **Параметр в одном слоте не измеряется.** Каждая новая формулировка должна стоять минимум в двух слотах пака.
7. **Во время генерации брифов систему не трогать.**
8. **Остановка объявлений через панель необратима для открутки.** Смотри цифры перед нажатием.

## 7. Что делать, если…

| Симптом | Причина | Что делать |
|---|---|---|
| «нет ассета в meta_creatives» при разборе | превью объявления ещё не загружено | Приборная панель → «Прогнать цикл» или дождаться утреннего синка, затем повторить |
| «Разобрать» на неделе молчит, у шапки «Files API: не удалось инициировать загрузку» | у Gemini кончились предоплаченные кредиты (402) | пополнить баланс проекта в AI Studio; код менять не нужно |
| В Telegram «токен Google Drive не работает (invalid_grant)» | протух refresh-токен Drive, ТЗ в Google Docs не откроются | в репозитории запустить `node scripts/google-oauth.mjs --drive`, войти в браузере; перевести OAuth consent screen в In production, чтобы не повторялось |
| «частичный ответ Plurio — повтори» | CRM отдала не все лиды | повторить синк; система специально не пишет неполные данные |
| «Семей недостаточно» в отчёте | мало креативов, отличающихся одним параметром | норма для короткого окна; смотреть бивариат по всему периоду |
| «Проверка не пройдена» | модели нашли противоречия в данных | проверить маппинг и синк, собрать отчёт заново; не принимать решений по этому отчёту |
| Конструктор заблокирован «Собрать отчёт» | у продукта нет отчёта | сгенерировать отчёт на экране «Отчёт» |
| «⚠ Не все части сгенерировались» | часть брифов упала по времени | «Сгенерировать только слоты, у которых ещё нет брифа» |
| В таблице ровно 1000 строк | потолок выборки, а не факт | сообщить разработчику, это ошибка экрана |
| Параметры не считаются по новому объявлению | имя в кабинете не по кодам или объявление не размечено | Маппинг объявлений → вкладка «К разметке» |
| «Канал не активен» у TikTok | нет ключей TikTok в окружении | норма, пока канал не подключён |

## 8. Чек-лист первой недели нового пользователя

День 1. Войти. Выбрать канал «Meta Ads», продукт «Бух». Прочитать Dashboard и Приборную панель, не нажимая кнопок остановки. Открыть Библиотеку, найти по коду формулировки из любого имени объявления в кабинете, прочитать текст по всем четырём осям.

День 2. Открыть «Отчёт», выбрать «Прошлый месяц», прочитать проверку, HELPS / HURTS, семьи, разбор. Сопоставить три виннера из отчёта с их креативами на Приборной панели.

День 3. Маппинг объявлений: посмотреть вкладку «К разметке», разметить два объявления руками, чтобы понять, что такое формулировка. Запустить «Разметить Gemini пачкой» на остальных.

День 4. Субъективный анализ: собрать прошлую неделю, разобрать параметры у пяти креативов, написать «Что делаем?» по каждому, собрать AI-разбор.

День 5. Конструктор: пересобрать пак на 10 слотов для статики, прочитать объяснения каждого слота, не принимать. Затем принять тестовый пак на 4 слота и сгенерировать брифы, прочитать один бриф целиком и выгрузить в DOCX.

После этого ты видел весь круг. Дальше система используется еженедельно по разделу 4.
