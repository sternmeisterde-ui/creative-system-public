# 08. Ударения

## Словарь
`data/analysis/lang/stress.json` — 895,818 словоформ с ударением из Викисловаря (ключ: форма без ударения в нижнем регистре, значение: варианты с ударением).
`stress_variants.json` — формы с несколькими вариантами. Важно: большинство «вариантов» — грамматические омографы разных форм (го́да/года́, ру́ки/руки́),
а не ошибки. Ударение в омографах определяется формой: род. ед. «го́да» vs мн. «года́». В брифе для озвучки такие слова помечать ударением явно.

## Правило для брифа
Ставить знак ударения (буква + U+0301, например «звони́т») в тексте для диктора/TTS во всех случаях:
1. Омографы: за́мок/замо́к, му́ка/мука́, о́рган/орга́н, а́тлас/атла́с, стои́т/сто́ит, до́ма/дома́, го́ды/года́, бо́льшая/больша́я.
2. Глаголы прошедшего времени женского рода с ударением на окончание: поняла́, взяла́, дала́, ждала́, брала́, спала́, приняла́, начала́сь, отдала́ (в корпусе сотни употреблений).
3. Заимствования и бренды (см. ниже).
4. Имена собственные и фамилии.
5. Числительные, записанные словами.
