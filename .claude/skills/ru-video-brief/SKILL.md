# ru-video-brief — бриф на видео с живой русской речью

Скилл делает одно: превращает оффер, сегмент и цель ролика в **бриф, который можно отдать актёру, диктору или TTS**, и в котором речь
звучит как у живого человека из топа русскоязычного Instagram. Не «правильный текст», а **устная речь**: короткие реплики, «ну», «вот»,
«короче», «на самом деле», обращение к одному человеку, история от «я», контраст, повтор, без книжных слов и триад.

Правила не выдуманы: они извлечены из 5027 роликов (только живые люди, без ИИ-генерации и TTS), 766 тысяч слов, 4912 разборов Gemini,
проверены на разрезах «топ по просмотрам» и «топ по ER». Каждое число ниже можно перепроверить в `references/`.

## Как устроен скилл
- **Воркфлоу** (ниже) — вход, 7 шагов, формат выдачи, гейты качества.
- **references/01–02** — портрет речи и синтаксис: цифры-нормы. Читать всегда.
- **references/03** — хуки: типы, перевес по ER, шаблоны и примеры дословно. Читать всегда.
- **references/04** — нейтив-фразы по функциям. Читать всегда, брать 5–8 фраз в сценарий, не больше.
- **references/05** — структура и призыв. **06** — лексика, сленг, мат. **07** — бан-лист и таблица замен. **08** — ударения. По необходимости.
- **references/09** — где полные данные и как обновлять. **10** — контекст вашего продукта (`references/10_product_context.md`, заполните под себя).
- **scripts/check_brief.py** — линтер речи. Обязателен перед выдачей. **lookup.py** — ударение, регистр, толкование, примеры из корпуса и классики. **inspire.py** — дословные хуки/фразы/призывы из корпуса.
- **templates/brief.md** — формат выдачи.

Запуск скриптов: `python3 scripts/<скрипт>`. Для морфологии (причастия, регистр по Ожегову, леммы) нужен `pip install pymorphy3 pymorphy3-dicts-ru`; без него линтер работает, но эти две проверки пропускает. Если корпус ru-reels лежит рядом, используйте его venv с pymorphy3.
В переносимой версии словари лежат в `data/` внутри скилла (усечённые под лексику корпуса); полная версия и корпус — на диске пользователя, см. `references/09_sources.md`.

## Вход
Собрать из запроса пользователя и файлов (персоны, JTBD, лендинг). Чего нет — спросить одним пакетом, не по одному:
1. **Продукт и оффер**: что продаём, что конкретно получает человек, цена/условия, ограничения (что нельзя обещать).
2. **Сегмент и Job**: кто смотрит, какую задачу решает, точка А → точка Б, язык клиента (дословные фразы из интервью/звонков — бесценны).
3. **Цель ролика**: охват (виральность), вовлечение (ER), лиды (клик/заявка). От цели зависят адресат, темп и призыв (см. шаг 2).
4. **Площадка и формат**: Reels / TikTok / Meta Ads / автовеб; говорящая голова, сценка-диалог, закадр, UGC-селфи.
5. **Длительность**: 15 / 30 / 45 / 60 / 90 с. Бюджет слов = длительность × 2.1–2.25 (125–135 слов/мин).
6. **Ограничения**: тон, табу (мат по умолчанию исключён), обязательные факты, юридические формулировки, немецкие термины.
7. **Сколько вариантов**: по умолчанию 1 сценарий + 3 хука для A/B.

Всё, что дал пользователь о клиенте («они хотят…», «им важно…») — гипотеза. Если это расходится с языком корпуса или клиентов, сказать об этом в брифе одной строкой.

## Шаги

### 1. Загрузить нормы
Прочитать `references/01_speech_profile.md`, `02_syntax_rhythm.md`, `03_hooks.md`, `04_native_phrases.md`. Остальное — по ходу.

### 2. Речевой паспорт ролика (заполнить до текста)
| Решение | Правило из корпуса |
|---|---|
| Адресат | **Одно на ролик.** Охват → «ты» (у топа по просмотрам «ты» 0.8/100 против 0 у низа). Вовлечение/эксперт → «вы». Сценка-диалог — смешение допустимо. Без адресата нельзя: у слабых роликов медиана «ты» и «вы» = 0. |
| Голос | я-история (31% корпуса) для охвата и UGC; эксперт-вы для доверия; сценка для юмора. «Я/мне/меня» присутствует всегда: ~3 на 100 слов. |
| Темп | Охват 120–130 сл/мин (топ по просмотрам 124), вовлечение 125–135. Медиана корпуса 133. |
| Длительность | Топ по ER длиннее (69 с против 48). Для охвата 30–45 с, для ER 60–70 с. |
| Тип хука | По цели, см. шаг 3. Не приветствие, не анонс, не цифра-факт. |
| Скелет | хук → история или проблема → объяснение → пример → вывод → мягкий призыв (доминирующая последовательность корпуса). |
| Призыв | Комментарий (перевес 106/77) или подписка (81/40) или директ; **не ссылка (5/31), не «сохрани» (4/23)**. 71% сильных роликов без призыва — можно закончить панчем. |
| Регистр | Разговорный. Мягкие ругательства («блин», «капец», «жесть») по согласованию. Сленг как приправа: прям, реально, круто, кайф, огонь, база, норм, окей. |

### 3. Хук — три варианта из разных типов
Перевес по ER (топ-четверть / низ-четверть): провокация-утверждение 1.23, обещание-результата 1.04–1.16, я-история 1.01, ты-ситуация 1.0,
цитата-реплика 2.47 (мало данных), **вопрос 0.80, диалог-сценка 0.58, императив 0.77, цифра-факт 0.30**.
- Для охвата и UGC: **я-история с конкретикой** («Я разведёнка, 42 года, 2 детей») + **ты-ситуация** («Если у тебя диплом лежит, а ты…»).
- Для вовлечения: **провокация-утверждение** (спорный тезис точкой) + **обещание результата** («Сейчас покажу, после чего…»).
- Вопрос — только как вопрос-ситуация про зрителя («А вы знали, что…», «Вы когда…»), не абстрактный.
- Первая фраза ≤ 12 слов. Начинать с «я», «у меня», «если ты», «а вы знали», «ну что», «сейчас покажу», «стой». Никаких «всем привет, меня зовут», «в этом видео».
- Дословные примеры сильных хуков по типу: `inspire.py hooks <тип>`.

### 4. Сценарий — реплики с таймкодами
Писать **как говорят, а не как пишут**. Контрольные нормы на 60 секунд (~130 слов):
- 15–20 реплик; половина по 2–5 слов; одна–две длинные по 15–20 (история, объяснение). Медиана предложения 6 слов.
- Каждая пятая реплика начинается с «и», «а», «ну», «вот», «да».
- 2–3 заполнителя в местах смены мысли: «ну», «вот», «короче», «слушай», «честно», «на самом деле», «по факту». Ноль заполнителей = читка; больше 6 на 100 слов = каша.
- 1–2 вопроса на ролик (не два подряд). Один контраст («раньше/сейчас», «а это/а вот это»). Один повтор слова или фразы ради эмоции.
- Конструкции устности: «у меня/у тебя/у нас» (не «иметь»), «потому что» (не «поскольку»), «то есть», «что-то/какой-то» для неважных деталей, «вот так вот», «мы с тобой».
- 5–8 нейтив-фраз из `references/04` по функции: открыть мысль, честность («на самом деле», «если честно»), реакция («да ладно», «ничего себе», «я в шоке»), связка («так вот», «кстати»), время («прямо сейчас», «в какой-то момент»). Не больше, иначе пародия.
- Ноль: причастий и деепричастий, «который» дважды подряд, триад через запятую, «не просто…, а…», книжных слов из `references/07`, ИИ-штампов («важно отметить», «в современном мире», «давайте разберёмся»).
- История рассказывается в настоящем времени («прихожу, сажусь, молчу»). Конкретика вместо оценки: не «было страшно», а «руки трясутся, когда набираю номер».
- Факты продукта — только те, что есть на лендинге. Факты вашего продукта — в `references/10_product_context.md`.

### 5. Кадр, текст на экране, подача
- К каждой реплике: что в кадре и что человек делает (одно действие), текст на экране (≤ 6 слов, не дубль речи, а акцент или цифра).
- Подача для диктора: темп, где пауза (перед панчем, после вопроса), где ускорение (перечисление), где интонация вверх. Отметить намеренные заполнители и повтор, чтобы их не «почистили».
- Немецкие термины для русскоязычных в Германии — кириллицей с ударением в скобках: Jobcenter (джобце́нтр), Ausbildung (а́усбильдунг).

### 6. Ударения для диктора/TTS (`references/08`)
Знак ударения (буква + U+0301, «звони́т») обязателен: в омографах (за́мок/замо́к, го́да/года́, до́ма/дома́), в женском прошедшем времени
(поняла́, взяла́, дала́, ждала́, начала́сь), в заимствованиях (телегра́м, инстагра́м, лайфха́к, дире́кт, капучи́но, конте́нт), в именах и числительных словами.
Проверка слова: `lookup.py stress <слово>`. Линтер подсветит пропущенные.

### 7. Проверка и выдача
1. Сохранить сценарий в файл по `templates/brief.md` и запустить `check_brief.py <файл> --wpm <темп>` (для сценки `--dialog`).
2. Все **красные** пункты исправить и перепроверить; жёлтые — исправить или объяснить в брифе одной строкой, почему оставлено.
3. В бриф вставить блок «Проверка речи» с итоговыми числами линтера.
4. Выдать бриф по шаблону: паспорт → 3 хука → сценарий-таблица → подача → проверка → варианты для теста с гипотезой по каждому.
5. Файл сохранить туда, куда просит пользователь; по умолчанию `Skills-Results/ru-video-brief/<дата>_<продукт>_<сегмент>.md`.

## Гейты качества (не выдавать, пока не пройдены)
- Линтер: 0 красных.
- Хук ≤ 12 слов, тип из списка с перевесом ≥ 1.0 для цели, без приветствия и анонса.
- Адресат один, «я» присутствует, заполнители 2–3/100, медиана реплики 5–8 слов, ≥ 30% реплик ≤ 5 слов.
- Призыв: комментарий / подписка / директ / панч без призыва. Не ссылка, не «сохрани».
- Ни одного слова из бан-листа, ни одного причастия, не больше одной триады.
- Ударения расставлены в трудных словах, омографах, заимствованиях, именах.
- Факты продукта совпадают с лендингом; всё, что не проверено, помечено как гипотеза.

## Чего скилл не делает
Не придумывает офферы и сегменты (это `nmt-*` и исследование), не монтирует.
Он отвечает за одно: чтобы речь в ролике звучала как у живого человека из топа, и чтобы это можно было проверить числом.
